# Как запустить модель

Следуйте инструкциям ниже для настройки окружения и запуска проекта.

1. **Скачайте репозиторий**  
   Загрузите все файлы проекта на локальный компьютер.

2. **Установите необходимые библиотеки**  
   Откройте терминал в папке проекта и выполните следующие команды:
    cv2:
    ```bash
   pip install opencv-python
    ```
    ```bash
    pip install ultralytics
    ```
    ```bash
    pip install torch
    ```
3. **Запустите программу**
    ```bash
    python model.py
    ```
4. **Завершение работы**
    Для корректного выхода из программы нажмите клавишу **q**.
